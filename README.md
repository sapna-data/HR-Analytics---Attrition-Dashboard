# HR-Analytics---Attrition-Dashboard
An interactive  Excel dashboard built to analyze employee attrition, workforce, demographics and performance metrics. 

🚀 Project Overview
This project provides deep insights into employee attrition patterns, helping management understand why employees are leaving and identifying key drivers related to department performance, monthly income, gender distribution, and performance ratings.

📈 Key Performance Indicators (KPIs)
1. Total Attrition: Tracks the exact number of employees who left the company (15).
2. Attrition Rate: Calculated at 30% to highlight the overall organizational turnover percentage.
3. Average Monthly Income: Stands at ₹61,820 to analyze salary distributions across different job roles.
4. Average Performance Rating: Highlights the overall workforce performance standards.

📊 Visualizations & Insights Included
1. Attrition Status: Percentage breakup between active employees (No: 70%) and departed employees (Yes: 30%).
2. Role-wise Monthly Income: Visualizing income trends across various organizational roles.
3. Department-wise Attrition: Identifying which departments face higher turnover rates.
4. Gender Distribution: Equal balance overview (Male: 50%, Female: 50%).
5. Performance & Attrition Matrix: Evaluating performance slabs against retention.

🛠️ Tools & Technologies Used
Microsoft Excel: Advanced Pivot Tables, Slicers, Data Cleaning, Formularies, and Dashboard Design.
